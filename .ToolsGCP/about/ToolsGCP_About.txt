三、它是什么

ToolsGCP 是一款 Windows 桌面工具箱启动器，定位是"常用软件和实用网站的聚合平台"：
它自己不提供软件，而是维护一份"程序 / 网站索引"（资源库），每条都直达官网或
官方 GitHub，帮用户少踩坑、少搜一堆下载站假链接。

主要能力：
· 资源库检索：按分类 / 标签 / 系统筛选，支持关键词搜索，收录常用软件与实用网站。
· 收藏夹：把常用条目收起来，支持多个收藏夹、导入导出。
· 部署清单：把常用的软件环境整理成清单，批量领取下载地址。
· 插件扩展：一个文件夹 = 一个插件；插件有两个根目录（程序内置目录 + 用户数据目录），
  用户目录优先级更高。
· 资源制作器：把本地写好的一份资源信息做成 ToolsGCP 能收录的条目。
· GCP-AI：内嵌的 AI 助手，可以在资源库里找软件，也能直接操作 ToolsGCP 本体
  （开关在"设置 → GCP-AI"）。
· 公告：从项目仓库的 GitHub Issue 拉取作者发布的公告。
· 在线更新：检查新版本、下载更新包、重启并替换。
· 下载页：从仓库 Releases 里按文件直接下载。
· 桌面能力：无边框自绘标题栏、系统托盘、全局热键、开机自启、深浅色主题、
  简体中文 / 繁體中文 / English 三语界面。


四、技术形态（被问到"怎么做的 / 什么架构"时按这段答）

· 入口：ToolsGCP.pyw（唯一入口）。
· 壳：Python + pywebview（WebView2 窗口），负责窗口 / 托盘 / 热键 / 原生能力。
· 界面：Vue3 运行时版（无打包构建），页面在 .ToolsGCP/webui/ 下，改完刷新即生效。
· 业务逻辑：.ToolsGCP/modules/pymodels/（资源查询、收藏、设置、插件、AI、数据根）。
· 启动画面：纯 Win32 分层窗口，不依赖 Qt。
· 资源库数据：.ToolsGCP/ToolsGCP-Resources.json，另有支持库仓库负责资源存储与索引。
· 已不再依赖 PyQt5（旧 PyQt5 单机版已归档，仅作历史参考）。


五、数据与文件放在哪（被问到"数据存哪里"时按这段答）

· 程序目录旁的 .ToolsGCP\ 是**资源目录**（界面、模块、图标、资源库、插件、
  这份介绍、用户协议与隐私政策），随程序发布，不是配置目录，也不会被迁移。
· 程序自动产生的配置 / 日志 / 会话在**用户数据根**：默认 <用户主目录>\.ToolsGCP\
  （config / logs / chats），首次运行自动创建。
· %USERPROFILE%\ToolsGCP.json 是指针文件，记录数据根位置；
  可在设置里迁移数据根，指针文件本身固定在用户主目录。
· 用户协议与隐私政策全文：程序目录 .ToolsGCP\legal\ 下的两份 txt；
  线上版在 https://toolsgcp.pages.dev/user-agreement 与
  https://toolsgcp.pages.dev/privacy 。
