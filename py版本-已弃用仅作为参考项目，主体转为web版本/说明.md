# py 版本 · 已弃用，仅作为参考项目

> **主体已转为 web 版本（pywebview + Vue3）。**
> 这个文件夹里只有一份**完整的旧 PyQt5 单机版存档**，不参与运行，只用来对照
> 「原版长什么样 / 原来怎么实现」。

---

## 内容

```
备份py版本/     ← 完整的 py 版本存档（用户提供，原样保留、未做任何改动）
```

`备份py版本/` 里是**一整套能独立运行的旧版**：

```
ToolsGCP.pyw                    旧入口（PyQt5 单机版）
requirements.txt                旧版依赖（PyQt5 + PyQt-Fluent-Widgets + Frameless-Window）
README*.md / docs/              旧版文档
.ToolsGCP/modules/pymodels/     interfaces/（28 个页面）+ ui/（17 个）+ widgets/（7 个）
.ToolsGCP/Icon/ .ToolsGCP/images/ .ToolsGCP/plugins/ .ToolsGCP/tools/ .ToolsGCP/research/ …
.github/workflows/release.yml   旧版的打包工作流
```

## 为什么 web 版不会用到这里

web 版自己的 `.ToolsGCP/modules/` 里留着 `pymodels` 的 **core / utils / constants / splash_screen**
（业务逻辑、语言包、日志器、全局热键），页面层已经全部换成 `webui/` 前端 + `desktop/` 外壳。
也就是说：**这个文件夹删掉，web 版照样能跑。** 留着只是为了"抄逻辑时有证据可看"。

## 想跑旧版怎么办

直接把 `备份py版本/` 整个复制到别处，进去 `pip install -r requirements.txt`，
再 `python ToolsGCP.pyw` 即可（它是自包含的，不依赖本仓库其它目录）。
