# ---------- 运行必需 ----------
pywebview>=6.2,<7            # 桌面窗口外壳（Windows 走 WebView2 / winforms 后端）

# ---------- 仍然必需：原版业务层里的这几个模块是 PyQt5 写的 ----------

#   pymodels/utils/global_hotkey.py→ 全局快捷键（QAbstractNativeEventFilter）

#   pymodels/core/ai/agent_runtime.py → 插件 agent 的工具注册（import qfluentwidgets）

PyQt-Fluent-Widgets>=1.11,<2
