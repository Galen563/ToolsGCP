# 样例素材（不是完整导出）

这是 `ToolsGCP_UI_Asset_Exporter.py` 实际跑出来的一份**样例子集**（1x 原生无损）：
40 张单组件透明 PNG + 12 张整程序整图 + 清单。

- `manifest.json`：样例清单（字段与完整导出一致，含 `assets` 与 `screens` 两段）。
- `assets.csv`：同一份清单的表格版。
- `dark/**`：单组件透明 PNG（RGBA，四角 alpha=0）。
- `screens/dark/**`：整程序整图（每个页面 / 每个切换分页一张，1440×900）。
- `README-使用说明.md`：工具自动生成的完整说明（剪映摆放方式、已知限制）。

完整导出请自己运行（一次约 10 分钟，1050 张 + 78 张整图）：

```bash
python ToolsGCP_UI_Asset_Exporter.py --yes --themes both --out "D:/素材"
```
