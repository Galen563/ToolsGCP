# 项目资料 · 文档与开发测试

> 这里的东西**都不参与程序运行**，只是给开发者/自己看的资料。
> 放在这里是为了让项目根目录清爽：根目录只留「程序本体 + README + 依赖 + .git + .github」。

---

## 目录

```
docs/        设计与规范文档
  py-to-web-spec.md           原版 PyQt 行为逐条提取（带 文件:行号 证据），web 版对齐依据
  py-maker-deploy-spec.md     资源制作器 / 部署清单的原版规格
  resources-schema.md         ToolsGCP-Resources.json 的字段契约
  LOGGING.md                  日志格式与排查方法
  SECURITY_AND_ENGINEERING.md 安全模型与工程规范
  UPDATE_PLAN.md              自动更新方案（constants.py 的更新识别契约引用了它）
  VERSIONING.md               版本号规则（constants.py 引用了它）
_devtest/    开发自检工具（还能跑的才留）
  serve.py                    本地静态服务器（把 webui/ 喂给浏览器，带 mock pywebview.api）
                              用法：python _devtest/serve.py 8791 → 浏览器开 http://127.0.0.1:8791/
  regression.py               无头 Edge 逐页回归（量 mustaches / pageCount / overlaps / JS 报错）
                              ⚠️ 需要一台没有被沙箱限制的 Windows（Chromium 多进程要开命名管道）
  gen_icons.py                按参数生成 icons.js 里的星形 / 齿轮路径（改那两个图标时用它）
tools/       构建与维护脚本
  build_en_fallback.py        生成 pymodels/core/en_fallback.py（语言键的英文兜底表）
  add_i18n_keys.py            批量补语言键
  detail_preview.py           详情页渲染预览辅助
```
